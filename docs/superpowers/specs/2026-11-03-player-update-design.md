# Impuls 1.1: обновление плеера

Пользователь запросил большое обновление GUI, удобства плеера и API, сворачивание в трей и управление из его меню; выбрал обновлённый ретро-стиль нулевых и работу с субагентами.

## Дизайн

Сохраняем GTK4/GStreamer, серебристые панели и синий дисплей. Обновляем композицию, интервалы, состояния кнопок, двухстрочные музыкальные списки и читаемость. Cantarell/sans-serif для контента, monospace для времени и технических метаданных. Узкое окно скрывает второстепенные колонки. Эквалайзер и визуализация остаются доступны.

Рассмотрены полная смена стека, современный тёмный минимализм и развитие текущего GTK-интерфейса. Выбрано развитие текущего интерфейса: сохраняет рабочий звук, нативность, тесты и выбранную пользователем ретро-эстетику.

## Функции и контракты

- StatusNotifierItem и DBusMenu через Gio без GTK3/новых обязательных зависимостей. Меню: показать окно, воспроизведение/пауза, предыдущий/следующий трек, выход. Закрытие скрывает окно только при доступном хосте трея; явный выход освобождает ресурсы. При отсутствии хоста окно закрывается обычным образом.
- Обновить/повторить текущий запрос: заново получить данные и сбросить кеш коллекции без прерывания звучащей очереди. Устаревшие ответы не меняют новый экран.
- Воспроизвести весь текущий список / перемешать его; действия с отдельным треком, копирование метаданных и переход на страницу сервиса.
- Удобное отключение звука и возврат громкости, справка по горячим клавишам, доступное меню приложения.
- Локальные несекретные настройки (громкость, качество, эквалайзер) сохраняются атомарно, некорректные значения игнорируются. Токены остаются исключительно в Secret Service.
- Исправить обнаруженную ошибку Gst toggle: не показывать успешное воспроизведение при отказе смены состояния.

Дополнительно пользователь запросил несколько визуализаций и адаптивность. Режимы: сглаженные ленты, столбцы, зеркальный спектр и орбита. Все используют реальные 32 полосы спектра; анимация прекращается без аудиосигнала. Режим сохраняется между запусками. Проверяем узкие и низкие окна, длинные кириллические названия, управление без горизонтального обрезания.

## Проверка

Юнит-тесты API и звука без аккаунта; тесты GUI с реальным GTK; отдельная D-Bus-сессия с тестовым хостом трея; снимки широкого и узкого окон на демонстрационных данных. Реальные авторизация, платные потоки и рабочий стол пользователя без отдельного действия не трогаются. Обновить README, метаданные версии и собрать RPM при доступных инструментах.
